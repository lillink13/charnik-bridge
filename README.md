# Чарник — мост к Initiative Tracker

Плагин Obsidian для мастера: связывает **стол Чарника** (планшеты игроков) с **Initiative Tracker** (obsidian-ttrpg-community).
Инициатива, КД, хиты и состояния с планшетов игроков попадают в трекер; порядок хода, раунд и монстры — игрокам;
урон, который мастер наносит в трекере, приходит игроку предложением (применить / половину / удвоить / другое / отклонить);
летопись боя — на планшетах.

Это репозиторий **только с релизами** (исходники живут в приватном монорепо Чарника). Здесь лежат готовые
`main.js`, `manifest.json`, `styles.css` для установки через BRAT.

## Установка через BRAT

1. Obsidian → Settings → Community plugins → Browse → установить **BRAT** (TfTHacker), включить.
2. Settings → BRAT → **Add Beta plugin** → вставить `lillink13/charnik-bridge` → Add Plugin.
3. Settings → Community plugins → включить «Чарник — мост к Initiative Tracker».
4. Обновления: BRAT проверяет их сам при запуске Obsidian (или Settings → BRAT → Check for updates).

Нужен установленный **Initiative Tracker** 13.x. Плагин только для настольного Obsidian (Windows / macOS / Linux).

## Настройка

1. В Чарнике (`/app`): Настройки → **Стол** → «Я мастер» → **Создать стол**. Там код для игроков и кнопка
   **«Ключ для Obsidian»** (показывается один раз).
2. В настройках плагина вставить ключ → **Подключить**. В статус-баре: «Чарник: онлайн · N мс · игроков онлайн/всего».
3. **Привязки**: каждому листу игрока за столом — игрок из настроек Initiative Tracker («Подобрать по именам»).
4. **Трекер → «Переключить на “ставить 0”»** — иначе при новом бое трекер сам бросит инициативу игрокам поверх введённой с планшетов.

Игроки: на планшете Настройки → Стол → ввести код стола (один раз на персонажа).

## Установка руками (без BRAT)

Скачать из последнего релиза `main.js`, `manifest.json`, `styles.css` → положить в `<vault>/.obsidian/plugins/charnik-bridge/`
→ Settings → Community plugins → ⟳ → включить.
